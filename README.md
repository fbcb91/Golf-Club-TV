# Golf Club TV — landing page

Pagina "coming soon" per presentare Golf Club TV ai creator.
Un unico file statico (`index.html`), nessuna build: si può pubblicare con GitHub Pages, Netlify, Vercel o qualsiasi hosting statico.

- Lingua: inglese di default, pulsante EN/IT in alto (link diretto in italiano: `?lang=it`).
- Email di contatto: modificare `CONTACT_EMAIL` nello script in fondo a `index.html`.
